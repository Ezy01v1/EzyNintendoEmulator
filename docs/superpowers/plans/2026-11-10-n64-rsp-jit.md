# RSP JIT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add an optional x86-64 RSP block compiler and prove correctness and whole-game performance against the interpreter.

**Architecture:** AsmJit emits straight-line blocks of at most 32 instructions. A standard-layout view points to live RSP state; a bounded run record carries the local clock and retirement count. Control instructions and delay slots remain interpreted. IMEM writes invalidate a per-console cache.

**Tech Stack:** C++20, MSVC 19.44 x64, CMake presets, AsmJit pinned at `677a10bac2c24f7e068cf1f9e675bf51c7b534ea`, doctest.

**Spec:** `docs/superpowers/specs/2026-11-10-n64-rsp-jit-design.md`, approved by the user's instruction to continue.

## Global Constraints

- Maximum block length 32 instructions; never cross 4 KiB IMEM end.
- Version-11 serialized machine state unchanged; no native pointers/cache serialized.
- Preserve 1/2-cycle parity, event ordering, r0, DMEM wrapping and big-endian accesses.
- Control flow/COP0/BREAK and single-step stay interpreted initially.
- CMake `EZY_N64_RSP_JIT=OFF` excludes AsmJit; non-x64 builds use interpreter.
- Keep interpreter default until historical ROM validation and >=10% median elapsed improvement.
- No push, merge or ROM commits; use existing local build tree and an isolated `codex/` branch.

## Review Focus

- Event tied with RSP and MI active on entry: fall back or retire exactly one instruction (Task 4).
- DMEM 0xFFF and source/destination aliases: native byte-wrapped loads/stores match reference (Task 3).
- IMEM mirrors, DMA and state rollback: invalidate before reuse of a previously compiled PC (Task 2/4).
- Budget ends in a partial block: all PC/GPR/phase changes materialized exactly once (Task 3/4).
- Allocation failure/cache exhaustion: return to interpreter and never execute stale/null code (Task 3/5).

## Final validation and outcome

All six implementation tasks are complete; performance acceptance was not achieved.
The interpreter remains the runtime default, with synchronous RDP.

- ON: 187 cases / 2857 assertions per suite, all four RSP/RDP combinations pass.
- OFF: 179 cases / 1973 assertions per suite, both RDP modes pass; no AsmJit project dependency. Ruling: sequential OFF/ON configuration in the same preset tree respects the repository's prescribed commands. ON was restored and Debug tests and Release runner/frontend rebuilt.
- Exact MK64 images at 120/300/600 fields; opposite-backend saved-state continuation passes.
- User-reported null read reproduced in pinned AsmJit allocator tree insertion after multi-block soft reset. Hard reset between native calls fixes it; repeated multi-block invalidation regression and real-game debugger run pass.
- Fresh review completed for ABI, cycle limits, wrapping, invalidation and fallback. Added hot-code mirror/DMA/load/rollback coverage; follow-up review found no remaining actionable issue.
- Historical systemtest ROM unavailable; no local cargo/rustup or official release binary. Its 2984/3721 baseline remains unverified.
- Three cold runs per mode, alternating: interpreter 11.932/11.139/10.163 s, JIT 50.500/45.708/43.917 s. Median CPU 9.500 vs 39.391 s. Exact images in all six runs.
- JIT median wall time 45.708 s vs interpreter 11.139 s: 4.10 times slower. Per 300 fields, native 76,828,052 / fallback 31,073,143 (71.2% native), 191,691 compilations, median compile time 33.660 s. Compilation dominates.
- Next scope to evaluate: safely reuse identical microcode translations across IMEM generations. This architecture change is not included in this delivery.
- Detailed results appended to the spec and recordatorios. Local only; no merge, push or ROM staging.
