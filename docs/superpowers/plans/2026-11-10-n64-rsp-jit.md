# RSP JIT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional x86-64 RSP block compiler and prove correctness and whole-game performance against the interpreter.

**Architecture:** AsmJit emits straight-line blocks of at most 32 instructions. A standard-layout view points to live RSP state; a bounded run record carries the local clock and retirement count. Control instructions and delay slots remain interpreted. IMEM writes invalidate a per-console cache.

**Tech Stack:** C++20, MSVC 19.44 x64, CMake presets, AsmJit pinned at `677a10bac2c24f7e068cf1f9e675bf51c7b534ea`, doctest.

**Spec:** `docs/superpowers/specs/2026-11-10-n64-rsp-jit-design.md`, approved by the user's instruction to continue.

## Global Constraints

- Maximum block length 32 instructions; never cross 4 KiB IMEM end.
- Version-11 serialized machine state unchanged; no native pointers/cache serialized.
- Preserve 1/2-cycle parity, event ordering, r0, DMEM wrapping and big-endian accesses.
- Control flow/COP0/BREAK and single-step stay interpreted initially.
- CMake `EZY_N64_RSP_JIT=OFF` excludes AsmJit; non-x64 builds use interpreter.
- Keep interpreter default until historical ROM validation and >=10% median elapsed improvement.
- No push, merge or ROM commits; use existing local build tree and an isolated `codex/` branch.

## Review Focus

- Event tied with RSP and MI active on entry: fall back or retire exactly one instruction (Task 4).
- DMEM 0xFFF and source/destination aliases: native byte-wrapped loads/stores match reference (Task 3).
- IMEM mirrors, DMA and state rollback: invalidate before reuse of a previously compiled PC (Task 2/4).
- Budget ends in a partial block: all PC/GPR/phase changes materialized exactly once (Task 3/4).
- Allocation failure/cache exhaustion: return to interpreter and never execute stale/null code (Task 3/5).
