## Triangle attribution

Optional `RdpTriangle` rows now group primitive counts by opcode, texel usage,
whether all shade gradients are zero, full combiner word and other modes. These
count triangles reaching gradient setup after early validation/clipping, not
pixel cost. A synchronous instrumented baseline
race run also matches the reference image/state.

The earlier 800-triangle group under other modes `EF882CFF0F0A4000`, responsible
for 15,360,000 writer attempts, splits into 400 opcode-12 triangles with varying
shade gradients and 400 opcode-14 triangles with uniform shade and no texels
actually selected by the combiner. All use combine `FCFFFFFFFFFE793C`.

Consequently, caching one output color across the whole group would be invalid.
But its active one-cycle formula has RGB/alpha zero products and SHADE as both
addends, so it can directly return the current shade color without evaluating
the general equation. The varying-shade triangles benefit too.

## Candidate

The candidate added a check at the start of `combine` for the exact active
cycle-1 selector pattern used by one-cycle mode. It ignored unused cycle-0
selectors and excluded two-cycle mode and chroma key. It advanced noise once
even though the formula does not use it, and applied existing nine-bit saturation
to all four shade components. No derived state or input cache was introduced.
Shader, blender, depth, texture and rasterization rules were unchanged.

This differs from rejected per-channel null-product checks and combiner input
predecode: it bypasses the entire general equation for one exact pipeline.

New tests cover 512 changing nine-bit shade values, noise progression, changes
to unused cycle-0 fields, chroma key, two-cycle behavior, and immediate addend
changes. Seven Debug suites pass: N64 206 cases / 65,381 assertions per mode.

Uninstrumented comparisons use three alternating fresh-process pairs against
the frozen post-rectangle baseline, the same 1500–1900 window, interpreter and
synchronous RDP. Every run compares the complete binary state and image.
Evidence is under ignored `build/shade-only/`.

## Follow-up

Final validation after restoring the post-rectangle renderer: Debug rebuilt and
all seven suites pass (206 N64 cases / 65,381 assertions per mode). Release
runner/frontend rebuilt with counters OFF. A paired 120-field boot check matches
image and complete state exactly. The short check is not performance evidence.
The historical systemtest and 1900+120 cross-mode continuation were not repeated:
production rendering behavior is restored to the version already validated in
`2026-11-15-n64-constant-rectangle.md` (2,984/3,721, 737 known failures).

Improve measurement controls, including investigating fixed-core paired runs,
before retrying this small specialization. Do not infer a speed benefit from
the sample share, best pair, or arithmetic simplification. The profile is useful
for selecting further work, but does not override uninstrumented measurements.
